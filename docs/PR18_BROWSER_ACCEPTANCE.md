# PR-18 — Приёмка надёжности iScribe

## Два независимых уровня доказательств

1. **Автоматический Chromium E2E / Playwright**: настоящий React-интерфейс, браузерные Cache API и IndexedDB, перезагрузка вкладки, обработка 35 окон записи *логической длительности* 14:31, реальное скачивание и чтение трёх текстовых файлов, ошибка/повтор диаризации. Распознавание и декодирование заменены **детерминированными имитациями**; реальные веса Whisper не загружаются, настоящее качество речи и GPU не тестируются.
2. **Аппаратная приёмка**: реальная запись 14:31, модель Whisper Small с GPU, WebGPU→WASM, выключение сети и повторная загрузка страницы. Она **не выполнена** в PR-18, поскольку исходный MP3 и доступ к пользовательскому браузеру с GPU не предоставлены. Не ставить метку «проверено на реальной записи» до фактического прохождения.

## Автоматические проверки в CI

- `verify`: `npm ci`, TypeScript, ESLint, Vitest, production build.
- `browser-acceptance`: реальный headless Chromium, Playwright `@playwright/test@1.56.1` установлен отдельно от production deps и lockfile, браузер установлен в GitHub Actions. Запуск `npx playwright test`.
- Playwright использует отдельную **непроизводственную** страницу `tests/e2e/harness.html`, отсутствующую в публикации; перед загрузкой данных сайта использует чистый browser context каждого теста.
- CI-артефакты ошибок: `playwright-failures` (trace), срок хранения 7 дней. Настоящие записи и транскрипты в репозиторий или CI не добавлять.

### Форма протокола

На каждую попытку указать: дата и время, ОС/версия браузера, GPU, объём RAM, WebGPU/WASM, Whisper-модель, размер и длительность файла, номер окна и граница checkpoint до/после reload, результат, наблюдённый сетевой трафик и скриншоты/логи консоли с удалением личных данных.

**Релизный критерий:** PR-13…PR-18 слиты в нужном порядке; все обязательные CI проверки зелёные после объединения; G1–G6 и G10 подтверждены на реальном MP3, G7–G9 явно отмечены как пройденные либо документированные ограничениями. Без этого выпуск считать только инженерно протестированным.
