# iScribe — PR-18: протокол приёмки надёжности

## Фактическое покрытие CI (без нейросетевых весов)

Проверяются в Vitest + fake-indexeddb: запись 14:31 (871 с, **35 окон** с шагом 25 с), последовательность checkpoint, итоговый прогресс 100%, сохранённый ASR до диаризации, три TXT-варианта, повторная загрузка состояния через новый JobRunner, продолжение с окна 3 без дублирования двух сохранённых, и сбой/повтор диаризации без повторного ASR. Дополнительно предыдущие тесты PR-13–17 проверяют перезапуски Worker, watchdog, отмену, Cache API и атомарность IndexedDB.

Это **симуляция pipeline**, а не работа реального Whisper, WebGPU, WebNN, Hugging Face, микрофона или операционной системы. fake-indexeddb не гарантирует сохранность реальных данных браузера после crash/OOM.

## Gate перед релизом

1. PR-13 и PR-14 должны быть интегрированы с цепочкой PR-15 → PR-16 → PR-17 → PR-18; после разрешения конфликтов повторить CI **на итоговом main**.
2. Выполнить H01–H12 в реальном браузере, особенно запись 14:31 и возобновление после перезагрузки.
3. Любой FAIL оформить как отдельный defect/PR; при незаполненном протоколе считать выпуск **не прошедшим аппаратную приёмку**.

Ограничение платформы: при закрытии/краше вкладки, сбое GPU-процесса и OOM приложение не может гарантировать продолжение вычислений; сохранённые транзакции IndexedDB позволяют перезапустить работу вручную.
