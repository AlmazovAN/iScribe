# PERF-05 — Audio Pipeline

Streamed audio only: the initial uncommitted window uses the existing checked reader. When Whisper starts, a bounded FIFO prepares the next one or two PCM windows using the same decoder, strictly one read at a time. Full-buffer mode already has decoded PCM and is unchanged. The Resource Manager targets 0/1/2, conservatively limited by browser memory hints (unknown or <=4 GiB: zero; reported 8 GiB: at most one). No new model instance, window length or overlap change.

Producer uses existing decoder, resampling, PCM validation and per-stage watchdog limits. It never writes IndexedDB, publishes progress or reserves recovery. The consumer imports only checked PCM in original order at the next window; previous checkpoint is already committed. Successful prefetched diagnostics are published at consumption, so their trace timestamps denote publication, not actual start. A failed speculative read retires lookahead and transfers the original error into existing durable recovery; no extra retries. No reads across mandatory decoder rotation. ASR recovery disables new prefetch for the remainder of the run; already prepared PCM from the unchanged decoder may still be consumed. Profile changes affect new admissions, existing queued windows drain in order. Cancellation/failure discards queue and aborts its watchdog before the existing decoder cleanup. A timed-out native decoder may settle late but cannot publish to job state.

Benchmark JSON reports scheduled/consumed/ready hits/failed, peak queued and wait/preparation durations. Two 30 s 16 kHz float32 PCM windows are <=3.84 MB of payload, excluding backing buffers, decoder scratch, resampling, active window and model memory. Timings overlap ASR and must not be summed as total cycle time. No performance guarantee; test with real long recordings in PERF-09.

Tests added: bounded FIFO and backpressure, failure/abort, mocked runner verifies next decode starts during current ASR, exactly-once checkpoint and existing recovery after speculative failure. Existing rotation and regression suites remain. Full CI and hardware status NOT TESTED until actual results.
