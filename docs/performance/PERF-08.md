# PERF-08 — Speaker Optimization

Independent speaker Worker receives a validated WASM thread target before preload/inference. Use the existing resource policy and Worker-side checks; standalone remains one thread, isolated launch up to eight, one thread after ASR recovery when forceSingleWasmThread applies. Apply profile at start of speaker pass, not during inference. Preserve the pinned engine WASM/q8 patch, cache manifests, model IDs and alignment thresholds. GPU/NN and embedding batching are intentionally NOT implemented: the pinned engine exposes runSpeakerPass, not safe independent provider/batching controls, and real-device equivalence has not been demonstrated.

Speaker alignment uses a start-sorted interval index with prefix maximum end and bounded edge search, avoiding full scans in typical sparse timelines. Original overlap, weak evidence, ambiguity and edge thresholds remain unchanged; within-speaker sum order remains stable. Worst case dense overlapping intervals still require more candidates. No change to source ASR or output ordering. Already committed ASR remains exportable if speaker pass fails; existing retry only speakers remains. Streamed diarization remains unsupported.

Benchmark records last pass configuration and Worker acknowledgement, audio duration, transport mode, progress milestones, successful/failed passes, alignment elapsed time, queries and candidate counts. Milestones from existing progress messages are NOT exact Pyannote/WeSpeaker kernel timings. No claim of actual threads, GPU use or speed gain. Existing single speaker worker lifecycle and transfer path retained. No speaker embedding cache or new model downloads introduced.

Tests cover interval index against exhaustive inclusive search, sparse timeline and existing quality regressions, milestone reporting and speaker Worker message ordering. PERF-07 collapsed log regression fixed in parent commit 4d03227: summary includes latest event label, full rows remain lazy. CI and real hardware NOT TESTED until actual results. Compare isolated 1/2/4/6/8 where available and diarization accuracy in PERF-09.
