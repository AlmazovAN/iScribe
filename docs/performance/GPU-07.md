# GPU-07 — WeSpeaker GPU Acceleration (experiment)

Production patches pin WeSpeaker and Pyannote to WASM/q8. No production model or engine changes are made. The development-only lab uses a locally selected self-contained q8 ONNX graph (<=64 MiB), fixed synthetic FP32 filterbank-like inputs [batch,198,80], and expects a single model input and a selected two-dimensional FP32 embedding output. The 80 mel components are documented by the model preprocessor configuration; graph signature, dynamic batch support and artifact identity are not confirmed. Select the actual embedding output if the model has multiple outputs. The same file is used in all variants; the lab does not verify its identity.

## Run
Close the running iScribe tab, run npm ci and npm run dev on this branch, open /tests/gpu/wespeaker-lab.html. Compare WASM and requested WebGPU for batch sizes 1, 2, 4, 8. Eight identical independent feature examples per sequence; one warmup, three measured sequences. Timings include inference and output availability, exclude input preparation and validation. Separate workers, 120-second whole-variant timeout, stop button, tensor disposal, one fresh WASM batch-1 recovery after WebGPU failure. If WebGPU batch-1 fails, larger WebGPU batches are skipped. JSON includes timings, cosine and pairwise similarity drift, not features or embedding vectors. Select requested WASM threads (1/2/4/8); effective configuration is capped by cross-origin isolation and hardware concurrency, not a measured active thread count. Per-variant speed ratios use WASM batch-1. Final selection first checks baseline repeatability and exact count of three parity results, then compares the fastest quality-qualified WebGPU against the fastest quality-qualified WASM variant at the selected thread configuration. Preliminary screening: >=1.10x throughput ratio against that WASM reference, minimum cosine >=0.999 and maximum pairwise cosine drift <=0.01 in all measured sequences. Cancelled experiments do not produce a final selection. Not a real speech quality or release gate.
