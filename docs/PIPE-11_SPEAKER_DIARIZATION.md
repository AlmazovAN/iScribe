## Verified current engine contract

Existing ModelManager.diarize accepts a full Float32Array at 16 kHz, max 3600 seconds. Existing pinned engine 0.1.1 patch runSpeakerPass releases ASR, creates segmentation/embedding runners, invokes one diarize(audio,...) over the full recording, releases the diarizer in finally. Host receives SpeakerTurn[] with start/end/speaker and caps count at 100000. Existing q8/WASM Pyannote + WeSpeaker, ResourceManager, Worker retirement and PIPE-05 bounded retry unchanged. Current host exposes neither per-cluster embeddings nor cross-window cluster matching contract. Thus cluster labels represent the output of one whole-recording pass only; identical labels from independent passes do NOT establish identical voices. No new acoustic model, clustering algorithm, DER improvement or actual long-file support asserted.

## Turn geometry and word assignment

All production assignment calls now pass actual full PCM duration. Invalid/unknown labels and wholly out-of-source turns ignored, trailing overrun clipped to source end. Same-speaker overlapping/touching intervals merged as before; no merging different clusters by proximity or text. The default remains existing segment overlap assignment and legacy retry behavior.

Optional word assignment is enabled by ?alignment=ctc&speakers=words with diarization selected, full PCM and eligible durable checkpoint service, and at least one accepted word in validated PIPE-10 report. If alignment is disabled, unavailable or empty, use normal segment assignment. For accepted source segments only:
- Query the global turn interval index for each word's actual absolute interval.
- Sum overlap by existing speaker cluster after same-label union. Require best overlap >=50% of word duration; competing positive overlap >=75% of winner is ambiguous. These thresholds are provisional. No nearest-speaker compensation for words; uncovered, weak and ambiguous words remain unknown.
- Group consecutive words of same label (including unknown) within each source segment; split at original text offsets on label changes. Preserve all original characters in local speaker rows, including punctuation and whitespace. Time boundaries use first and last aligned word in each run. Unaligned segments retain normal segment policy, including its legacy limited edge compensation.
- Keep immutable original ASR segments and plain/time TXT behavior. Existing speaker TXT now uses experimental split rows only for opted-in jobs; formatter normalizes whitespace and sorts by timestamp as before. Original source segments that overlap in time may interleave in speaker TXT; this is not a guarantee of conversational order or acoustic identity.

Word counts describe the subset accepted by CTC, not all words in recording. Separate stats for aligned/fallback source segments, split source segments, output rows, aligned/labeled/unknown words, ambiguity/weak/uncovered. Legacy speaker diagnostics count output rows in word mode (not source ASR count); compare word accuracy/coverage separately. Do not equate higher label coverage with better diarization. Existing interval index avoids general all-pairs scans but worst-case heavily overlapping pathological turns remain a performance risk; measure real CPU and memory.

## Durable replay and identities

Word assignment consumes validated local alignment RAW, verified by PIPE-10 pointer, and global diarization RAW keyed by decoder profile, PCM fingerprint and existing engine contract. Before committing output, compute stats; store speakerSegments and wordSpeakerStats revision 1 / word-v1 atomically in existing JobStore transaction (no DB migration). Metadata guard rejects rollback, count mismatches, missing speaker rows and incompatible alignment counts. Once published, mode persists even when flags are absent. Resume uses same RAW turns; missing/corrupt RAW fails closed and never automatically substitutes an independent speaker pass. Recomputed word output and summary must match stored result; preserve prior ASR and speaker rows on failure. Explicit new acoustic run with independent cluster labels requires a new job in this mode. This is a deterministic replay guard, not security authentication of arbitrary tampered database content. Before first word-mode commit, a saved prior global RAW may be reused; if missing and not pinned, existing bounded pass may compute it. Default segment mode retains explicit rerun behavior. No persistent cross-recording speaker identity, no voiceprint catalog. No upload of voice data/labels/text.

Diagnostic panel shows labeled aligned words / aligned words, with ambiguity, weak and uncovered counts. Sanitized diagnostic JSON exports validated numeric word summary only; no raw cluster labels, word spans, transcript or PCM. Existing full TXT/speaker TXT and private alignment JSON stay local.

## Streaming feasibility and next steps

Actual long-windowed input (including >128 MiB source route, e.g. 63:54) remains baseline without speakers. Independent block-wise Pyannote+WeSpeaker passes followed by concatenation or matching numeric labels cannot solve global speaker identity. Proposed future implementation: verified engine API for bounded segmentation/embedding export; global clustering of bounded embeddings or deterministic centroid tracking with overlap reconciliation, uncertainty rejection, one global label mapping, immutable model/threshold/revision and source timeline identity; durable chunk/embedding checkpoints, local-only storage, memory and retry caps. Require tests with A-B-A reappearance across block boundaries, simultaneous speakers, silence, missing/low quality embeddings, false merges and false splits; compare to a full-pass reference on recordings within current limit. Actual backend support and global clustering must be established before enabling streaming; no implementation of these components in PIPE-11.
