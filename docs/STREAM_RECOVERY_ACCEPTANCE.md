## Ограничения

Watchdog работает при доступном цикле событий активной вкладки; не устраняет полный зависший процесс браузера или IndexedDB. JS heap не равен памяти процесса, GPU или WASM. Ротация 20 окон и фрагменты 5 с — предварительные параметры. Проверка PCM не доказывает корректность всех сжатых кадров MP3. Строгая проверка покрытия может отвергнуть допустимое округление границ; реальные MP3 обязательны для приёмки. Новый декодер при локальной проверке не воспроизводит накопление ресурсов. Никакой автоматический тест не доказывает устранение исходного отказа без реального прогона.
