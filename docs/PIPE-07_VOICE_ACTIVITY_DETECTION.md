## Stage contract and safe rollout

For full PCM opt in via query string ?vad=silero on production page or local standalone HTML. Default remains existing ASR path. JobRunner records explicit vad-disabled, vad-streaming-unavailable, asr-already-committed or vad-unavailable skips. A full input is verified by PCM gate, then VAD generates an advisory absolute half-open speech interval map. Transfer one owned copy of at most 30 seconds to the existing auxiliary Worker instance at a time; model recurrent state and fractional frame carry across blocks without resetting at 30-second boundaries. Pad only final inference frame with zeros, clamp output to original samples. Existing ModelManager disposes ASR first, owns VAD Worker via auxiliary Worker slot, applies watchdog/cancellation/retirement guard and terminates on every exit. On ordinary model/runtime failure, explicit baseline fallback (one pass, no automatic VAD retry); cancellation, storage/RAW integrity and unconfirmed Worker disposal must not be hidden by fallback. VAD not yet part of PIPE-05 durable attempt ledger; an interrupted unpublished optional pass can be rerun on explicit resume.

Provisional policy: start p>=0.35, end after 8 consecutive frames p<0.20 (~256 ms), pad each speech interval by 4000 samples (250 ms) each side, merge intersecting/touching intervals, retain short detected speech. These are engineering defaults, not validated speech recall or upstream defaults. No confidence threshold is proof of no speech. Map coverage and bounds are validated; numeric trace reports frames, detected/padded speech samples and interval count. No interval content, raw PCM, exception messages or transcript in new diagnostics.

Eligible full-PCM checkpoint jobs persist returned map before host structural validation using existing hashed RAW store (stage vad, decoder profile, exact PCM fingerprint, pinned blob and policy revision). Verified compatible map is reused; corrupt RAW/hash failure is not re-inferred. A structurally invalid map is retained for diagnosis and baseline fallback. A cache miss or disabled experimental mode cannot invalidate prior fixed-window ASR: map is advisory. No schema migration. No independent persisted frame-by-frame probabilities or VAD resumable recurrent state yet.

**Do not drop any audio on PIPE-07.** Fixed 30-second windows/25-second step, overlap ownership, ASR RAW identity, retry and text commits remain unchanged. Even all-low/empty VAD map still sends every original window to Whisper. Long/windowed PCM route retains current baseline; no false claim of complete VAD. PIPE-08 consumes a validated speech plan only after real recall/quality acceptance and explicit checkpoint-plan revision. No claimed hallucination or throughput improvement yet.
