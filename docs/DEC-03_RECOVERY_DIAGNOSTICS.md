# DEC-03 — Recovery & Diagnostics (stage 3/4)

- Persist decoder kind, full/windowed route and implementation revision before decoding, using existing IndexedDB metadata (no schema migration). New jobs choose requested provider; existing saved checkpoints without identity are treated as legacy (assumes no unreleased experimental checkpoints). Resume pins original decoder, rejects changed route/revision or FFmpeg sample duration, retains committed text. Existing metadata cannot be silently overwritten by stale tabs.
- Typed FFmpeg failures and bounded numeric exit codes distinguish open/probe, decode/coverage, worker/protocol, timeout and PCM validation from ASR failures. No FFmpeg stderr, paths, raw exceptions, PCM or transcript in new exported diagnostic events. Failed audio-check report no longer exports arbitrary problem text.
- Existing stream watchdogs terminate the decoder before recovery. Transient worker/timeout and incomplete coverage during window reads use existing durable budget: reopen, then split into 5 s parts; max 2 recoveries per window, 5 per job. Deterministic format/decode/probe/protocol errors, invalid PCM, cancellation, storage failures and open failures do not auto-retry. Full-file FFmpeg gets one durable retry for worker/timeout only. ASR recovery reuses prepared PCM and is unchanged. No silent legacy fallback.
- Diagnostic JSON adds decoder identity, full-decode retry counter and fixed failure details. New trace events after selection identify decoder kind and route. Phase distinguishes audio and ASR. Exact seek fidelity, memory usage and causal relation to observed Whisper stalls remain unproven.
- Manual repeated job restart is not prevented; existing retry counters limit automatic recoveries, not all user-initiated attempts. No audio or transcripts sent to GitHub diagnostics.
- Added policy/provenance/privacy and durable-storage tests. All tests, both builds, real FFmpeg, hardware acceptance, npm ci and file:// remain NOT TESTED in this environment; mandatory local pipeline before main. No Actions dispatch.
