## Stage contract

Opt-in via ?alignment=ctc on the production page or local standalone HTML. Requires full PCM with eligible checkpoint service; streaming and legacy unsupported checkpoint route stay baseline. Whisper must first commit complete ASR; alignment runs before diarization. Existing Whisper session disposed before alignment worker is created. Host owns one request and a copied slice of at most 30 s; no overlap of live ASR and alignment sessions. Worker loads one model, sends model progress, returns one segment result at a time, releases its model and is terminated by host. Watchdog uses existing model-init timeout and 5 min visible idle per inference; cancellation/termination policy inherited. No automatic retry of alignment; interrupted unpublished optional pass can be rerun on explicit resume, not yet counted in durable retry ledger. Ordinary model/protocol failure falls back to original transcript; cancellation, checkpoint/storage failure and unconfirmed Worker disposal are not swallowed.

For each eligible ASR segment, crop to original interval (clipped to real source samples), never claim speech outside it. Compute CTC emissions from model and find highest scoring monotonic path for fixed known text with blank transitions and repeated-label separation. Map frames to original 16 kHz sample positions on 320-sample (20 ms) grid. Not a new ASR decode; never replace the text. Punctuation is not an acoustic token; offsets map original text including case and Unicode combining marks. Unknown characters/number tokens, mixed alphabets, empty text, invalid crop, digital silence, impossible path or insufficient score leave whole segment unaligned. Provisional gate: minimum character mean posterior 0.10, word mean 0.35. Scores are heuristic uncalibrated evidence, not accuracy probabilities. Alignment cannot recover a word omitted by Whisper, fix an incorrect transcript, or move a segment outside its original interval.

Bounds: 10000 source segments, total original text <=4 Mi UTF-16 code units, 4096 chars and 512 CTC target labels per eligible segment, 1500 frames, one model, work <=2x original sample count, stop accepting new segments at 50000 aligned words (bounded final row up to 50512). The report may be partial; no invented times for skipped segments. No streaming alignment, word splitting for speaker labels or segment boundary expansion here.

## Checkpoints and output

RAW alignment saved with existing hashed artifact store under source fingerprint + decoder profile + exact full PCM fingerprint + transcript SHA-256 (ordered start/end/text) + model revision/language/dtype + algorithm contract. Structural validation checks original word offsets, complete word coverage per accepted segment, monotone in-segment times and finite scores. After validation publish only small immutable checkpoint pointer/summary in existing job metadata, no new schema version. On resume, compatible RAW reused; already pinned report is checked even when flag is off; missing/corrupt pinned artifact fails closed, no silent rerun or overwrite. RAW can be reused after publication failure. No partial per-segment durable checkpoint during the pass; if interrupted before RAW publish, optional pass may be repeated. Previously committed text always unchanged.

Diagnostic panel shows aligned segments / total. Diagnostic JSON contains only counts, no word spans, transcript or fingerprints. Explicit private button JSON слов downloads iscribe_word_alignment.json with all original segments, original times, aligned flag and accepted words with original text offsets, start/end seconds and scores. This private export contains recording text: do NOT upload it to diagnostic GitHub repo. Plain TXT, TXT + time and speaker assignment deliberately retain existing Whisper intervals until real-device alignment quality acceptance.
