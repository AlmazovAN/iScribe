## Architecture / durable boundaries
Existing JobRunner owns FIFO, Web Locks, cancellation, decoder/model lifecycle, retries and all commits. CheckpointManager is a run-local artifact service using the existing JobStore; no competing queue or database. IndexedDB adds one store stage-artifacts-v3, compound key [job id, artifact key]. Existing source audio, ASR append-only chunks and speaker result stores remain unchanged. List/get jobs does not load large artifacts. Removal of a job also removes its artifacts in the same transaction; an artifact write requires the parent job to exist.

| Artifact | Durable boundary | Resume behavior |
| --- | --- | --- |
| Source fingerprint + contract | job metadata saved before decode | Rehash local Blob on every eligible run; mismatch blocks, never mixes text from a changed source |
| Full PCM | chunks up to 4 MiB each, SHA-256 per chunk, final manifest published only after all chunk transactions succeed | Exact matching decoder profile; verify all chunks and then normal PCM gate, no repeat FFmpeg |
| Stream PCM (uncommitted window) | one window, exact sample bounds and SHA-256 before ASR | First uncommitted window may use its checkpoint after validation; normal stream open still required |
| RAW Whisper ASR | per-window JSON, digest, persisted after successful inference and before absolute timestamp/overlap validation | Reuse exact matching RAW; no repeat model inference if validation or final text commit failed after RAW publication |
| Validated ASR | existing atomic append-only transaction of text and nextWindow; final asrComplete | previous committed windows not replayed; remains authoritative, not inferred from RAW or trace |
| RAW speaker intervals | JSON + digest after existing diarize() returns, before label assignment | reuse if assignment was not published; explicit retry of previously published speaker result still runs the speaker model |
| Assigned speakers / final text | existing job store speaker result + terminal job transaction | plain TXT available if speaker stage fails |

Deterministic fixed-window plan is recomputed cheaply; no standalone segmentation artifact at this stage. VAD, forced alignment and full reusable streaming PCM for later independent passes are future stages. No claim of fully general DAG artifact invalidation. The first uncommitted window cache is used at the beginning of a resumed run, when no speculative read is queued; subsequent windows keep existing prefetch order. After successful window text commit, the temporary stream PCM is deleted best-effort; cancellation/crash can leave an orphan under that job until removal. Full PCM and per-window RAW stay until job deletion. Full PCM still occupies RAM while in use (bounded chunks only avoid an extra whole-file copy for hashing/persistence); no storage quota guarantee.

## Identity and integrity
Source fingerprint is a versioned SHA-256 hash of source size, 4 MiB chunk size and ordered SHA-256 chunk digests. It is intentionally not the standard SHA-256 checksum of the whole source file; this bounds temporary memory. No filename or source digest is exported in diagnostics. PCM hashes cover exact local Float32 bytes. Identity keys incorporate source fingerprint, stage, version, input configuration; PCM key incorporates decoder kind, route, revision, format and optional expected sample count from pending #76 recovery. RAW ASR includes exact input PCM fingerprint, absolute window bounds, model ID, language and current engine/Transformers contract revision; RAW diarization includes exact full PCM fingerprint and speaker engine contract. These tags are not immutable hashes of remotely fetched model weights; pin or bump contract on changes in later stages. Backend fallback does not invalidate already produced RAW for identical input/settings. A new stage revision requires explicit compatibility review; old artifacts are not destroyed by a key miss. An incompatible job-wide artifact contract or source identity fails closed rather than rewinding committed text. User can create a fresh job, retain/export the old one.

RAW is a JSON representation of engine-returned records (including tagged NaN/Infinity) with SHA-256, not a byte-for-byte serialization of arbitrary JS objects. Existing ASR timestamp validation additionally requires string text. RAW validation failure leaves the raw record for review; automatic inference retry is not started. Manual retry of the same invalid RAW will fail again rather than silently overwrite it; create a new job after investigating/fixing the cause. If inference completes but RAW was never durably published (storage failure or cancellation), a later explicit resume can need to recompute. No general atomicity between inference and disk can be promised. Corrupted published manifests/chunks/RAW stop the job; missing manifest is a cache miss, incomplete chunks may be replaced on next save. Do not mix strict and compensated frame-recovery PCM on integration of #76.

## Compatibility and migration
Artifact checkpoints enabled by default for the actual default FFmpeg production runtime. Legacy decoder path and historical jobs with committed ASR but no source fingerprint continue existing resume behavior; never invent their source identity or claim old PCM compatibility. Injected test/alternate runtimes opt in explicitly via checkpointArtifacts. Web Crypto SHA-256 is required for eligible jobs; missing support is a visible failure, not unchecked cache reuse. Verify file://, actual browser persistence, quotas and source digest performance on target Windows device.

Database is upgraded from version 2 to 3 additively, without deletion of v1/v2 data or changes to v2 layout. Existing v1 lazy migration remains. Old binaries opening hard-coded version 2 will receive VersionError after upgrade. **Rollback to old HTML is not safe without a compatible reader/restore strategy.** Export important transcripts and preserve original audio before first migration; use a separate browser profile for migration/rollback rehearsal; never clear browser data to solve version errors. Blocked upgrade reports other tabs; a late connection is closed. Test migration and rollback constraints before deploying to normal profile. Browser origin/file:// storage and eviction remain limitations; no guarantee of retention after clearing site data.

## Diagnostics and failure handling
Existing bounded trace adds checkpoint-artifact saved/reused/cleanup-failed with stage/window; pipeline error can include closed artifactIntegrityFailure flag. Hashes, raw JSON, source file names, PCM and speaker labels are not included in exported diagnostics. Storage errors fail before subsequent dependent computation; no new retries or reset of existing durable retry counters. Prefetch stays read-only and existing atomic ASR nextWindow+text transaction is unchanged. Replayed raw has zero newly executed inference time; existing cumulative benchmark is not an independent hardware speed measurement. Added I/O/hash cost requires target-device profiling.
