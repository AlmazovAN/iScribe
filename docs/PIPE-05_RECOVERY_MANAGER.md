## Policy and decision

One initial attempt plus at most one recovery for an unfinished operation. The default global budget is 10 reserved recoveries per job lifetime, a conservative design value pending hardware acceptance. Healthy initial attempts do not consume the shared retry budget. Preserve existing tighter caps: one full FFmpeg recovery per job, five stream-window recoveries per job and now one recovery per stream window (instead of two). Historical counts are included in initial ledger; do not reset them. No automatic budget refill on reload, re-enqueue, backend change or stage transition.

| Operation | Unit | Automatic recovery |
| --- | --- | --- |
| Full decoding | one active decode cycle | Worker/timeout, if eligible; one retry, old full cap retained |
| Stream open | one active initial-open cycle | none; explicit resume can consume remaining attempt, rotation/recovery open is owned by current operation |
| Stream decoding | absolute window number | one fresh decoder: whole window for decode/worker/coverage; bounded 5-second split for resample watchdog |
| Whisper ASR | absolute window number | one recovery, fresh Worker, WASM/reduced-pressure route according to existing backend policy; resumed second attempt explicitly requests WASM |
| Speaker diarization | one active pass | one retry for known transient Worker/inference failure or timeout, conservative resources, one WASM thread |

The second stream attempt chooses one strategy, never runs whole then split as a third attempt. A split is one logical window attempt of at most six bounded reads. It is not six ASR attempts. Failed reopen consumes the reserved retry. Healthy planned stream rotation is not a recovery. Existing foreground-only idle timeouts and cancellation semantics retained. On Watchdog disposal callback failure, reject with worker-disposal-failed and do not automatically restart the operation; this is not proof of actual hardware Worker cleanup if a lower-level adapter swallows an error.

Automatic retries exclude invalid PCM/coverage shape errors, invalid RAW, checkpoint integrity and storage failures, cancellation, unavailable/model-load/network failures and known severe memory or permanent FFmpeg categories. Typed transient FFmpeg coverage errors on windowed decode remain eligible. ASR classification still uses existing engine codes plus conservative message heuristics for legacy uncoded Worker errors; arbitrary unknown errors are not retryable. Full damaged-frame policy #76 is not merged here, must be reconciled with unified reservation before acceptance.

## Durable reservation and compatibility

RecoveryLedger revision 1 is optional job metadata within existing IndexedDB v3; no new DB migration. Stores monotonically increasing serial, totalRecoveries and most recent per-operation unit, cycle, attempts, done. JobRunner remains single owner. Reserve before actual ASR, full decode, demanded stream decode/open and diarization, persist through JobStore before dispatch. Reserve retry before Worker recovery or decoder reopen, not after. A crash or cancellation after reservation counts conservatively even if execution did not start. If reservation persistence fails, do not invoke dependent computation. Existing Web Locks remain the job-owner exclusion; the ledger is not a replacement for cross-tab locks in environments without them.

Completed ASR operation is confirmed with text + nextWindow in the SAME existing transaction. No new ASR invocation after exhaustion; compatible verified RAW is still usable even when two reservations have been consumed. Compatible cached PCM or RAW confirms any unfinished operation without new reservation. The full/stream-open/stream-decode/speaker cycle may start again after a confirmed successful operation when an explicit resume or published-speaker retry needs it; previous retries are never refunded. No automatic retry of validation or storage failures. If RAW was never durably published, remaining budget is required for recomputation. An exhausted unfinished operation requires a new job after investigation; no hidden manual reset is introduced. Previous saved TXT stays available and independent FIFO items can proceed.

Legacy jobs lacking ledger start with prior fullDecodeRecoveries + streamRecovery.totalRecoveries. Historical current-window decoder retries without a completed artifact are conservatively considered exhausted; historical full decoder retry with no evidence of successful audio check or ASR progress is also treated as exhausted. No inference about pre-upgrade ASR attempt count is possible. Existing older stream counters of two retries remain readable, not reduced. JobStore rejects removal or rollback of a persisted ledger, conflicting equal-serial records and decreasing operation counters. No claim of tamper-proof storage.

## Scope / limitations

Read-only prefetch retains existing one-producer/two-window bound, no speculative job writes; its initial decode is accounted when the consumer takes a success or handles a failure, not before speculative dispatch. Abrupt termination before consumption can repeat speculative reads; demanded recovery and ASR attempts are durable. Initial model initialization/backend negotiation, WASM thread refresh, planned rotation and manual model preload are separate existing operations, not fully ledger-managed. A resumed exhausted ASR job may still open the stream or initialize the model before checking RAW/budget; it cannot start another ASR inference for the exhausted window. No complete process-level prevention of indefinite hardware hangs is implied. Watchdog counts visible-tab idle time, not an absolute wall-clock SLA. PIPE-06 will address resource lifecycle. New reservations add local metadata writes; benchmark overhead. Browser migration/rollback constraints from PIPE-04 remain.

Trace emits recovery-reserved and recovery-exhausted with closed operation, attempt, window, count and limit. Diagnostic JSON projects only validated closed ledger fields; no raw messages, paths, audio, text or fingerprints are added. Existing trace cap and source/decoder identity protections remain.
